# エージェント作業規約

このプロジェクトで作業するエージェントは、以下のルールを遵守してください。

## 1. セッション開始時

- まず `.agent/skills/references/project-overview.md` を読み、システム全体の構造・機能・アーキテクチャを把握してから作業を開始すること。
- 既存のコードパターンや命名規則を理解し、一貫性を保つこと。

## 2. 大きな変更を行った場合

以下のいずれかに該当する変更を行った場合は、`.agent/skills/references/project-overview.md` を **編集・追記** して最新の状態を反映すること。

- モジュール（ファイル）の追加・削除
- データフローの変更
- 技術スタックの変更・追加
- 機能の追加・削除
- ディレクトリ構造の変更
- 型定義の大幅な変更
